# RailTime

## Description

RailTime is an application aiming to provide a convenient way for residents living in Greater London to obtain real time traffic information and plan their journey.

## Planned Features

1. Detailed information of arrival trains
   - current estimated location
   - stations before and after the selected stop
   - estimated arrival time of stations after
2. Interchange information
   - nearest trains possible to interchange (including walking time between platforms)
3. Offline information
   - provide scheduled timetable information
   - perform offline route planning using timetable information
4. User friendly interface
   - view train arrivals at the closest station once the user open the app
   - customizable display of information
5. Widgets
   - widget showing train arrivals

## Tech Stack

1. Flutter
   - cross-platform mobile application framework
2. Sqlite
   - for timetables storage
